# Bloom for You

[Open the ASCII Garden](https://hanphp.github.io/bloom-for-you/)

Tap **Water** to grow a bouquet of 27 colored ASCII blooms. Tap a flower to
read its note, or tap **Reset** to start over.

## Run the desktop garden

With Python 3 and Tkinter installed, open this folder in VS Code and run
`python bored_flower.py`.

The browser version is a static site served by GitHub Pages.
